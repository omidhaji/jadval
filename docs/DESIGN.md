## ۲. هویت

- **نشانه:** دو خانهٔ مجاورِ جدول — **خانهٔ پُر** (زرشکی، راست) = آنچه می‌دانیم؛ **خانهٔ خالی** (سرمه‌ای، خطی، چپ) = جای خالیِ مندلیف برای کشف‌نشده‌ها. ترتیب ثابت است، گوشه‌ها تیز.
- **ورد‌مارک:** «جدول» با Estedad 900، **تک‌رنگ** (سرمه‌ای روی کرم، کرم روی تیره).
- **کاشیِ عنصر** (واحدِ اصلیِ گرافیک):

| جزء | جا | قاعده |
|---|---|---|
| شمارهٔ اپیزود | بالا-راست | دو رقم، لاتین (`01`) |
| نماد | وسط | دو حرفِ لاتین، اولی بزرگ، از نامِ انگلیسیِ شیء (Onion → `On`، Rain → `Rn`)؛ هم‌نامی با عنصرِ واقعی مجاز، تکرار نه |
| نام | پایین | شیءِ اپیزود (پیاز، قهوه، باران) |
| مدت | پایین | `26:04`، mono |

- **رنگِ کاشی:** انتخابِ سردبیری، بدونِ معنای دسته‌بندی — سرمه‌ای پیش‌فرض، زرشکی برای تأکید، کرم برای تنوع، مشکی کم‌کاربرد.
- **خانهٔ خالی:** اپیزودهای آینده، با تاریخِ سه‌شنبهٔ انتشار. **خانهٔ خط‌چین:** فقط حالتِ فیلترشده در رابط.
- **هاورِ کاشیِ لینک‌دار:** رنگِ متن ثابت می‌ماند و فقط زمینهٔ کاشی کمی روشن‌تر می‌شود (بدونِ کادر یا جابه‌جایی):

| کاشی | عادی | هاور | کنتراستِ متن در هاور |
|---|---|---|---|
| زرشکی | `#7A1E2B` | `#943344` | 6.6 : 1 |
| سرمه‌ای | `#16243C` | `#2C3D5B` | 9.6 : 1 |
| کرم | `#E7E2D5` | `#EFEBE1` | 13.1 : 1 |
| مشکی | `#111111` | `#2B2B2B` | 12.4 : 1 |

## ۳. سیستمِ طراحی

**رنگ**

| توکن | مقدار | کاربرد |
|---|---|---|
| `--color-bg` | `#F4F0E6` | زمینهٔ اصلی |
| `--color-bg-2` | `#E7E2D5` | زمینهٔ ثانویه، جداکننده |
| `--color-navy` | `#16243C` | تأکیدِ اول، خطِ ۲ پیکسلی، خانهٔ خالی |
| `--color-burgundy` | `#7A1E2B` | تأکیدِ دوم، خانهٔ پُر |
| `--color-text` | `#111111` | متن |
| `--color-hover` / `--color-pressed` | `#5E1621` / `#0E1828` | حالت‌های دکمه |

هر ترکیب حداکثر دو رنگِ برند + زمینه. طیفِ pH و رنگ‌های سبز/زرد/نارنجی/صورتی/بنفش مجاز نیستند.

**فونت**

| خانواده | کاربرد |
|---|---|
| Estedad 800/900 | تیتر، عنوانِ اپیزود، ورد‌مارک |
| Vazirmatn 300–700 | متن، رابط، دکمه، همهٔ برچسب‌های فارسی |
| IBM Plex Mono | فقط لاتین و عدد (`EP 01`، زمان، نماد). فارسی خودکار به Vazirmatn می‌رود |

روی متنِ فارسی `letter-spacing` ممنوع است (اتصالِ حروف را می‌شکند).

**مقیاسِ تایپ (دسکتاپ / موبایل، px)**

| توکن | اندازه |
|---|---|
| display | 76 / 40 |
| h1 | 50 / 30 |
| h2 | 36 / 24 |
| h3 / عنوانِ اپیزود | 26 / 20 |
| بدنه | 17 / 16 |
| کارت | عنوان 20، متن 15 |
| دکمه | 15 (کوچک 14) |
| متادیتا | 12 |

**چیدمان:** حداکثر عرض ۱۲۸۰؛ حاشیه ۴۰ / ۳۲ / ۲۰؛ نقاطِ شکست ۴۸۰، ۶۰۰، ۷۶۸، ۹۰۰، ۱۱۰۰، ۱۲۸۰؛ فاصله‌ها پایهٔ ۴ (4 / 8 / 16 / 24 / 40 / 80)؛ شعاع ۰؛ بدونِ سایه؛ جداکنندهٔ ۲ پیکسلی.

**هدر:** ارتفاع ۶۶ (موبایل ۶۰)؛ دکمهٔ «شنیدن اپیزود تازه» و همبرگر هر دو ۴۲ پیکسل؛ منوی کامل از ۹۰۰ پیکسل به بالا؛ زیرِ ۴۸۰ متنِ دکمه «اپیزود تازه».

## ۵. پلیر

- **پلیرِ کامل** (صفحهٔ اپیزود): نوارِ ۴۸ خانه‌ای که از راست پر می‌شود (خانهٔ زرشکی = جای فعلی)، ۱۵ ثانیه جلو/عقب، سرعت ۱ / ۱٫۲۵ / ۱٫۵ / ۲، دانلود، لینک از همان لحظه، بخش‌های اپیزود قابلِ کلیک.
- **مینی‌پلیر:** ثابت پایینِ صفحه (۷۲ پیکسل، موبایل ۶۸)، بینِ صفحه‌ها قطع نمی‌شود، جای پخش را نگه می‌دارد.
- **حالت‌ها:** آماده · بارگذاری · در حالِ پخش · خطا (تلاشِ دوباره / پلتفرمِ دیگر) · پایانِ اپیزود (پیشنهادِ بعدی) · ادامه از جای قبلی.

## ۶. نگاشتِ داده با Acast (برای ساختِ نسخهٔ نهایی)

| فیلد در طراحی | منبع در RSS |
|---|---|
| عنوان، توضیح | `title`، `description` / `content:encoded` |
| فایلِ صوتی | `enclosure@url` |
| مدت | `itunes:duration` |
| تاریخ (نمایشِ شمسی) | `pubDate` → تبدیل به تاریخِ شمسی |
| شمارهٔ اپیزود | `itunes:episode` |
| کاورِ پلتفرم‌ها | `itunes:image` (سایت کاشی را خودش می‌سازد) |
| نماد، نامِ شیء، رنگِ کاشی | در فید نیست — فایلِ کوچکِ تنظیماتِ سایت |
| اپیزودِ بعدی | تاریخِ آخرین اپیزود + ۷ روز |
